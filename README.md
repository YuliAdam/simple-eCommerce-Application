# 🚀 How to start

Clone the repo:

``git clone git@github.com:madsok/eCommerce-Application.git``

Install dependencies:

``npm ci``

# 📜 Available scripts

Run Vite dev mode:

``npm run dev``

Run Vite preview mode:

``npm run preview``

Create project build:

``npm run build``

Run ESLint:

``npm run lint``

Run Prettier:

``npm run format``

Initialize Husky:

``npm run prepare``

Run Vitest tests:

``npm run test``
